# DM Motors Garage 🚗🔧

Sitio web desarrollado para **DM Motors Garage**, un taller mecánico especializado en mantenimiento, diagnóstico, reparación y servicios automotrices.

🌐 Demo en línea: https://dmmotors.netlify.app/

## 📋 Descripción

DM Motors Garage es una plataforma web diseñada para brindar información sobre los servicios del taller, facilitar el contacto con los clientes y ofrecer una experiencia moderna y responsiva en dispositivos móviles y de escritorio.

El proyecto fue desarrollado como una solución web enfocada en la presencia digital de un negocio automotriz, aplicando buenas prácticas de diseño web, experiencia de usuario y desarrollo frontend.

## ✨ Características

* Diseño responsivo para móviles, tablets y computadoras.
* Sección de servicios automotrices.
* Galería interactiva de trabajos realizados.
* Formulario de contacto.
* Preguntas frecuentes (FAQ).
* Integración de redes sociales.
* Interfaz moderna y atractiva.
* Optimización para experiencia de usuario.

## 🛠️ Tecnologías Utilizadas

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL
* Git & GitHub
* Netlify (Despliegue)

## 🚀 Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/TU-USUARIO/dm-motors-garage.git
```

2. Acceder al directorio:

```bash
cd dm-motors-garage
```

3. Configurar la base de datos MySQL.

4. Ejecutar el proyecto en un servidor local como XAMPP o Laragon.
